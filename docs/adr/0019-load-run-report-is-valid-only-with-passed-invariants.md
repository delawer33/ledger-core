# Отчёт нагрузочного прогона годен, только если прошли инварианты

Скорость без корректности ничего не доказывает, поэтому генератор (`manage.py loadgen`,
`ledger/loadgen/`) устроен так, чтобы цифры нельзя было получить без проверки.

Решения, которые можно было принять иначе:

- **Проверка инвариантов обязательна и общая.** После остановки воркеров генератор вызывает
  `check_invariants()` из `ledger/invariants.py`, ту же функцию, что конкурентные тесты
  (ADR-0013). Не прошла: отчёт со статусом `FAILED`, команда завершается ошибкой. Сборщик
  таблицы для README (`loadgen table`) отвергает любой отчёт, у которого статус не `OK` или
  `invariants.ok` ложен, поэтому и подправленный вручную статус не пройдёт.
- **Воркеры ходят по HTTP, БД нужна только для проверки.** Нагрузка идёт через настоящий сервис
  (gunicorn, сериализация, идемпотентность), а `DATABASE_URL` генератору нужен лишь для
  инвариантов и счётчика дедлоков. Клиент на стандартной библиотеке (`http.client`, одно
  keep-alive соединение на воркера): новой зависимости нет.
- **Дедлоки из `pg_stat_database.deadlocks` до и после прогона.** Доступ к логам Postgres не
  нужен. Счётчик обновляется с задержкой около секунды, поэтому второе чтение ждёт 1,5 с.
- **ops/s считает только успешные (2xx) запросы,** перцентили всех запросов, включая ошибки.
  Бизнес-отказы (`insufficient_funds` и т.п.) попадают в разбивку по HTTP-кодам и кодам правил,
  а не скрываются.
- **Fee и payout не нагружаются.** Их форма зависит от тикета 26; генератор читает OpenAPI и
  пишет в отчёт найденные пути (`features.fee_payout_paths`), но операции не вызывает, пока их
  схема не зафиксирована в сценарии. Отсутствие этих эндпоинтов прогон не ломает.
- **Лимиты ресурсов в отдельном override,** `docker-compose.load.yml` (`cpus`, `mem_limit` для
  api, db, worker, scheduler) и `GUNICORN_WORKERS`/`GUNICORN_THREADS` в Dockerfile (по умолчанию
  1 и 1, как раньше). Override не меняет обычный `docker compose up`.
- **Сырые прогоны живут в `docs/load/`** (формат в её README); реальные результаты добавляются
  отдельно, генератор их сам не коммитит.
